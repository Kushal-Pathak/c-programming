# BCA C Programming

An interactive learning platform for first-semester BCA students to learn C programming and prepare for examinations.

## Features

- Beginner-friendly lessons and programming examples
- Interactive demonstrations, quizzes and automatic scoring
- Exam preparation and learning progress tracking
- Responsive layout for mobile, tablet and desktop
- Offline support with no external dependencies

## Course Status

- Unit 01: Problem Solving with Computer — Available
- Unit 02: Elements of C — Available
- Remaining 9 units — Coming soon

## Getting Started

Clone or download the repository and open `index.html` in a web browser. No installation or build process is required.

## Technologies

HTML5, CSS3 and vanilla JavaScript.

## Development

Refer to `AGENTS.md` for development guidelines and `DESIGN_SYSTEM.md` for consistent design and layout. Use `unit02.html` as the reference for new units.

The project can be hosted directly on GitHub Pages.
