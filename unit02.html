C Tokens

Unit 2 · Elements of C

Learning objectives

  • Define and classify C tokens.
  • Identify and count tokens in code.
  • Distinguish keywords, identifiers, constants and punctuators.

1. Definition

A token is the smallest individual meaningful unit of a C program recognized by the compiler. A program consists of tokens arranged according to the syntax rules of C.

int salary = 25000;

This declaration has five tokens.

Token Type
int Keyword
salary Identifier
= Operator
25000 Integer constant
; Special symbol (punctuator)

2. Types of C tokens

Introductory textbooks commonly divide tokens into six groups. In the formal C grammar, operators such as + and = are included in the punctuator category; the six-group classroom classification separates them for easier learning.

a. Keywords

A keyword is a reserved word with a predefined meaning and purpose in C. It cannot be used as an identifier. Examples: int, float, if, else, while, return.

b. Identifiers

An identifier is a name used to identify a program element such as a variable, function, array or structure tag.

int studentAge = 19;
float averageMarks = 78.5f;

studentAge and averageMarks are identifiers.

c. Constants

A constant is a fixed value directly represented in the program, such as an integer, floating-point or character constant.

int quantity = 50;
float price = 125.75f;
char grade = 'A';

50, 125.75f and 'A' are constants.

d. String literals

A string literal is a sequence of characters enclosed in double quotation marks. An ordinary string literal includes an automatically added null character (\0) at the end.

printf("Welcome to BCA");

"Welcome to BCA" is one token, even though it contains spaces.

e. Operators

An operator is a symbol that performs an operation on one or more operands (values or expressions).

total = price * quantity;

= is the assignment operator and * is the multiplication operator.

f. Special symbols (punctuators)

A punctuator is a symbol that has a specific syntactical meaning in C. Common non-operator punctuators help group, separate and terminate program elements.

Symbol Purpose
( ) Function calls and expression grouping
{ } Block of code
[ ] Array declaration and access
; Ends declarations and many statements
, Separates items, such as function arguments

3. Complete example

#include <stdio.h>

int main(void)
{
    int quantity = 5;
    int price = 200;
    int total = quantity * price;
    printf("Total: %d\n", total);
    return 0;
}

Output

Total: 1000
Type Examples in the function
Keywords int, void, return
Identifiers main, quantity, price, total, printf
Constants 5, 200, 0
String literals "Total: %d\n"
Operators =, *
Special symbols (, ), {, }, ;, ,

The #include line is a preprocessing directive. When asked to count C language tokens in a program, clarify whether preprocessing directives are included; preprocessing tokens have additional categories.

4. Important points and common mistakes

  • A token can contain one or more characters. totalAmount is one token; >= is one operator token.
  • Spaces, tabs and newlines can separate tokens. They are not normally counted as tokens.
  • Comments are replaced by whitespace during preprocessing and are not C language tokens.
  • C is case-sensitive: Marks and marks are different identifiers.
  • main, printf and scanf are identifiers, not keywords.
  • -15 contains two tokens: the unary minus operator and integer constant 15.
Character constant String literal
Single quotes: 'A' Double quotes: "A"
Represents a character value Represents a sequence of characters with a null terminator

5. Exam preparation

Be able to define a token, explain all six classroom categories with examples, identify tokens in a program and count them accurately. Remember that one word or one character is not necessarily one token.

Token explorer

Keywords and Identifiers

Unit 2 · Elements of C

Learning objectives

  • Define keywords and identifiers.
  • Recall the 32 traditional ANSI C keywords.
  • Apply identifier naming rules and compare both terms.

1. Keywords

A keyword is a reserved word in the C programming language with a predefined meaning and specific purpose. It is recognized by the compiler and cannot be used as a user-defined identifier.

Traditional ANSI C keywords (C89/C90)

auto break case char const continue default do double else enum extern float for goto if int long register return short signed sizeof static struct switch typedef union unsigned void volatile while

The original ANSI C standard has 32 keywords. Modern C standards add more keywords; 32 is not the total for every version of C.

int marks = 75;
if (marks >= 40)
{
    printf("Pass");
}
else
{
    printf("Fail");
}

int, if and else are keywords. Output: Pass.

Keyword Purpose
int, float, char Specify basic data types
if, else Select an execution branch
for, while Repeat instructions
return Returns control from a function
const Qualifies a type to prevent modification through that name
void Represents no value in a function return type
  • Keywords have fixed meanings and cannot be redefined by the programmer.
  • All 32 traditional ANSI C keywords are lowercase.

2. Identifiers

An identifier is a name used to identify a program element, such as a variable, function, array or structure. It allows a programmer to refer to that element by name.

int studentAge = 19;
float averageMarks = 78.5f;
char grade = 'A';

The three variable names are identifiers.

Rules for naming identifiers

  • For ordinary beginner identifiers, use letters (A–Z, a–z), digits (0–9) and underscores (_). Standard C also supports certain extended characters.
  • The first character must be a letter or underscore, not a digit.
  • Spaces and symbols such as @, -, $ and # are not allowed in portable ordinary identifiers.
  • A keyword cannot be used as an identifier.
  • Identifiers are case-sensitive. Avoid starting with underscores because many such names are reserved for the implementation.
Valid identifier Invalid identifier and reason
studentName student name — space
marks1 1marks — starts with digit
total_marks total-marks — hyphen
salary int — keyword
student_id student@id — special symbol
Float float — keyword

Program elements that use identifiers

Element Example
Variable int salary;
Function int calculateTotal(void);
Array int marks[5];
Structure tag struct Student
Macro name #define PI 3.14159

Good naming practices

Use meaningful names, a consistent naming style and avoid unnecessary abbreviations. Uppercase macro names are a convention, not a rule.

int a = 75;
int studentMarks = 75;

Both names are valid, but studentMarks is easier to understand.

3. Keywords vs identifiers

Keywords Identifiers
Reserved words Names of program elements
Predefined meaning Refer to particular elements
Defined by the language Usually chosen by programmers or libraries
Cannot be used as identifiers Cannot be identical to a keyword
Examples: int, return Examples: salary, main

4. Confusing points

Case sensitivity

int marks = 70;
int Marks = 80;
int MARKS = 90;

These are three different variables. float is a keyword, but Float is a valid ordinary identifier.

Function names are identifiers

printf, scanf, sqrt and strlen are library function names, not keywords. main is also an identifier. Do not reuse library names in ways that conflict with their declarations or reserved uses.

int calculateSquare(int number)
{
    return number * number;
}

calculateSquare names a function; number names a parameter. Every variable name is an identifier, but not every identifier is a variable name.

Data Types

Unit 2 · Elements of C

Learning objectives

  • Explain the classification and purpose of C data types.
  • Select suitable types and format specifiers.
  • Understand type modifiers, sizeof and numerical precision.

1. Definition

A data type specifies the kind of data an object can represent, its memory requirements, range of values and permitted operations. C is a statically typed language: expressions and variables have types determined during translation, even though some sizes (such as variable-length arrays) may be determined at run time.

int quantity = 10;
float price = 250.50f;
char grade = 'A';
double distance = 12345.6789;

2. Classification

Category Examples
Basic (fundamental) int, char, float, double
Derived Arrays, pointers, function types
User-defined Structures, unions, enumerations
Void void

This is a common classroom classification; the formal C type system groups types somewhat differently. Modern C also supports Boolean types (C99 _Bool, with bool through <stdbool.h> before C23; bool is a keyword in C23).

3. Basic data types

Integer (int)

An integer type represents whole numbers, including negative numbers, zero and positive numbers for signed types.

int population = 25000;
int temperature = -12;
int balance = 0;

Character (char)

The character type is an integer type commonly used to store character values. Characters have numerical codes according to the character encoding, such as ASCII.

char grade = 'A';
char digit = '7';

Floating-point (float)

The float type represents real numbers approximately using single-precision floating-point representation. Typical precision is about 6–7 significant decimal digits.

float percentage = 78.65f;
float temperature = 36.75f;

Double (double)

The double type represents real numbers using double-precision floating-point representation. On typical systems it provides about 15–16 significant decimal digits.

double pi = 3.141592653589793;
double distance = 123456.123456;
Type and typical size Typical range
char — 1 byte −128 to 127 if signed, 0 to 255 if unsigned
int — 4 bytes −2,147,483,648 to 2,147,483,647
float — 4 bytes Finite magnitude up to about 3.4 × 10³⁸
double — 8 bytes Finite magnitude up to about 1.8 × 10³⁰⁸

These sizes assume a common modern system with 8-bit bytes and IEEE floating-point formats. C does not guarantee all these sizes; sizeof(char) is always one C byte. <limits.h> and <float.h> provide implementation-specific limits.

Float vs double

float double
Single precision Double precision
Usually 4 bytes Usually 8 bytes
About 6–7 significant digits About 15–16 significant digits
Usually smaller range Usually larger range
float x = 3.14f; double x = 3.14;

4. Derived data types

Derived types are constructed from other types to represent more complex data or relationships.

Type Definition
Array Collection of elements of the same type in contiguous memory
Pointer Type used to represent the address of an object or function
Function Type specifying a function's return type and parameter types 
int marks[5];
int *ptr;
int calculateSum(int a, int b);

5. User-defined data types

A user-defined type is a type specified by a programmer to meet program requirements.

Structure (struct)

Groups related members, possibly of different types, under one structure type.

struct Student
{
    int roll;
    char grade;
    float marks;
};

Union (union)

Groups members that share the same storage. Usually one member's stored value is used at a time.

union Data
{
    int number;
    float price;
    char grade;
};

Enumeration (enum)

Defines an integer type with a set of named integer constants. By default, the first enumerator is zero and each following one increases by one.

enum Day { SUNDAY, MONDAY, TUESDAY };

The values are 0, 1 and 2.

Type definition (typedef)

The typedef keyword creates an alias (alternative name) for an existing type; it does not create a new distinct type by itself.

typedef unsigned int uint;
uint quantity = 50;

6. Void type

void represents the absence of a value. It is used for functions without a return value, function parameter lists with no parameters and generic object pointers (void *).

void display(void)
{
    printf("Welcome to BCA");
}

The first void means no returned value; the second means no parameters.

7. Type modifiers

Type modifiers specify variations in the size, range or signedness of basic types.

Modifier Purpose
signed Allows negative and nonnegative integer values
unsigned Allows nonnegative integer values only
short Integer type no wider than int
long Integer type at least as wide as int, or long double 
signed int temperature = -20;
unsigned int population = 50000;
short int age = 21;
long int distance = 987654L;
long long int debt = 9876543210LL;
long double value = 3.141592653589793L;
Typical integer type and size Typical range
signed char — 1 byte −128 to 127
unsigned char — 1 byte 0 to 255
short — 2 bytes −32,768 to 32,767
unsigned short — 2 bytes 0 to 65,535
int — 4 bytes −2³¹ to 2³¹−1
unsigned int — 4 bytes 0 to 2³²−1
long — 4 or 8 bytes Depends on system
long long — 8 bytes −2⁶³ to 2⁶³−1
unsigned long long — 8 bytes 0 to 2⁶⁴−1
Signed integer Unsigned integer
Negative, zero, positive Zero and positive only
Smaller maximum for corresponding type Larger maximum for corresponding type
signed int x = -50; unsigned int x = 50;

8. Format specifiers

A format specifier is a conversion specification beginning with % in a format string. It tells functions such as printf and scanf how to interpret a value or input.

Type printf / scanf specifier
int %d / %d
char %c / %c
float %f / %f
double %f / %lf
short %hd / %hd
long %ld / %ld
long long %lld / %lld
unsigned int %u / %u
long double %Lf / %Lf
String %s / %s (use a width limit with input arrays)

printf receives float values promoted to double; scanf needs a pointer to the actual destination type.

#include <stdio.h>

int main(void)
{
    int quantity = 5;
    float price = 125.75f;
    char category = 'A';
    double total = quantity * price;
    printf("Quantity: %d\n", quantity);
    printf("Price: %.2f\n", price);
    printf("Category: %c\n", category);
    printf("Total: %.2f\n", total);
    return 0;
}

Quantity: 5
Price: 125.75
Category: A
Total: 628.75

%.2f displays two digits after the decimal point.

9. The sizeof operator

sizeof is a unary operator that returns the size of an object or type in bytes. Its result has type size_t, printed with %zu (C99 and later).

printf("int: %zu bytes\n", sizeof(int));
printf("char: %zu bytes\n", sizeof(char));
printf("float: %zu bytes\n", sizeof(float));
printf("double: %zu bytes\n", sizeof(double));

Typical output: 4, 1, 4 and 8 bytes respectively.

10. Confusing points

  • '5' represents a character (ASCII code 53); 5 represents the integer five. Ordinary character constants have type int in C.
  • int x = 25.75; stores 25: conversion discards the fractional part when the result fits in the type.
  • 7 / 2 produces 3; 7.0 / 2 produces 3.5. The operand types matter.
  • Precision means significant digits, not decimal places. 12345.67 contains seven significant digits.
  • C has no built-in string type. A C string is a sequence of characters terminated by \0.
char name[] = "Ram";

The array holds four bytes: R, a, m, \0.

  • An unsuffixed floating-point constant such as 3.14 is a double; 3.14f is a float.

Variables

Unit 2 · Elements of C

Learning objectives

  • Declare, initialize and assign variables.
  • Explain scope, lifetime and memory address.
  • Avoid uninitialized values and invalid declarations.

1. Definition

A variable is a named storage location used to hold data during program execution. An ordinary modifiable variable can change its stored value. A variable has a name, data type, value, scope and lifetime.

int marks = 75;
marks = 85;

int specifies the data type, marks is the name, 75 is the initial value and 85 is the updated value. The variable refers to the same object during its lifetime.

2. Variable declaration

Declaration introduces the name and type of a variable to the compiler. It must be declared before use.

int age;
float salary;
char grade;
double distance;
int length, breadth, area;

A declaration can also be a definition that provides storage for the object. Not every declaration is a definition (for example, extern int total; normally declares an object defined elsewhere).

3. Variable initialization

Initialization provides an initial value when an object is defined.

int quantity = 10;
float price = 250.50f;
char grade = 'A';
int length = 15, breadth = 10;
int area = length * breadth;

An initializer can be a constant or, for ordinary local variables, an expression.

4. Variable assignment

Assignment stores or updates a value in an existing modifiable object using the assignment operator =.

int balance = 5000;
balance = 7000;
balance = balance + 1500;
printf("%d", balance);

Output: 8500. The right-hand expression is evaluated to obtain the value to store in the left-hand variable.

Declaration Initialization
Introduces a name and type Provides an initial value at definition
May omit an initializer Includes an initializer
int marks; int marks = 75;
Initialization Assignment
Initial value at definition Stores a value after definition
Happens when object is initialized May happen repeatedly
int marks = 75; marks = 85;

5. Naming rules

Variable names are identifiers. Use letters, digits and underscores, start with a letter or underscore, avoid reserved names, spaces and special characters, and remember case sensitivity.

Valid Invalid
studentAge student age
total_marks total-marks
marks1 1marks
salary float

6. Scope and lifetime

Scope is the region of a program in which an identifier is visible. Lifetime is the period during which an object's storage exists. They are different concepts.

Local variable

A local variable is declared inside a function or block and has block scope. An ordinary automatic local variable exists during execution of that block.

#include <stdio.h>
int main(void)
{
    int marks = 85;
    printf("%d", marks);
    return 0;
}

Global variable

A global variable is declared outside all functions. It has file scope and static storage duration, so it exists throughout program execution. Functions can refer to it when its declaration is visible.

#include <stdio.h>
int marks = 85;

void display(void)
{
    printf("%d\n", marks);
}
int main(void)
{
    display();
    printf("%d\n", marks);
    return 0;
}

Output: 85 on each of two lines.

Local variable Global variable
Declared inside a block Declared outside functions
Block scope File scope
Visible within its scope Visible to functions within its scope
Ordinary automatic local exists during block execution Exists throughout program execution
Uninitialized automatic local has indeterminate value Zero-initialized if no initializer is given

A static local variable still has block scope but exists throughout program execution. Prefer local variables unless shared state is required.

7. Memory address

A memory address identifies a location in memory. The address-of operator & obtains the address of an object. Use %p with a void * argument to display a pointer value.

int marks = 85;
printf("Value: %d\n", marks);
printf("Address: %p\n", (void *)&marks);

Possible output: Value: 85 and Address: 0x16fdfef8c. The actual address may differ each run.

8. Complete example: discount calculation

#include <stdio.h>
int main(void)
{
    int quantity = 5;
    float price = 450.0f;
    float discountRate = 10.0f;
    float total = quantity * price;
    float discount = total * discountRate / 100;
    float finalAmount = total - discount;
    printf("Total: %.2f\n", total);
    printf("Discount: %.2f\n", discount);
    printf("Final Amount: %.2f\n", finalAmount);
    return 0;
}

Total: 2250.00
Discount: 225.00
Final Amount: 2025.00

9. Common mistakes

  • Do not read an uninitialized automatic local variable. Its value is indeterminate and reading it can cause undefined behavior. Initialize it or assign a value first.
  • int a, b, c = 10; initializes only c. Use int a = 10, b = 10, c = 10; for all three.
  • int marks = 75; float marks = 85.5f; has conflicting declarations in the same scope.
  • int number = 10; number = 25.75; stores 25. The type stays int.
  • count = count + 5; is an assignment, not a mathematical equality.
= ==
Assignment Equality comparison
Changes stored value Compares values, produces 0 or 1
a = 10 a == 10

Constants and Literals

Unit 2 · Elements of C

Learning objectives

  • Define constants and literals.
  • Represent numeric, character and string literals.
  • Compare const-qualified objects and macros.

1. Constants and literals

A constant is a fixed value that does not change during program execution. A literal is a value written directly in the source code. C formally calls integer, floating-point and character literal tokens constants and separately classifies string literals.

const float PI = 3.14159f;
const int DAYS_IN_WEEK = 7;
int age = 20;
char grade = 'A';
char name[] = "Ram";

PI and DAYS_IN_WEEK name const-qualified objects; 3.14159f, 7, 20, 'A' and "Ram" are literal values. A variable initialized with a literal can still be modified unless it is const-qualified or otherwise nonmodifiable.

2. Types of literals

Integer constants

An integer constant is a numerical value written without a fractional part or floating-point exponent. It can be represented in different number systems.

Number system Example
Decimal (base 10) 25
Octal (base 8) 031
Hexadecimal (base 16) 0x19
Binary (base 2, standard since C23) 0b11001

Decimal uses digits 0–9; octal begins with 0 and uses 0–7; hexadecimal begins with 0x or 0X and uses 0–9 and A–F (case-insensitive); binary begins with 0b or 0B in C23. Suffixes such as U, L and LL help specify integer types.

int a = 25;
int b = 031;
int c = 0x19;
printf("%d %d %d", a, b, c);

Output: 25 25 25.

Floating-point constants

A floating-point constant represents a real number using fractional or exponent notation. Decimal scientific notation uses e or E for powers of 10.

Decimal Scientific notation
2500.0 2.5e3
0.0025 2.5e-3
45000.0 4.5e4

2.5e3 means 2.5 × 10³ = 2500.

By default, an unsuffixed floating-point constant has type double. Suffix f/F selects float; l/L selects long double.

Character constants

A character constant represents a character value enclosed in single quotation marks.

char grade = 'A';
char digit = '5';
printf("%c\n", 'A');
printf("%d\n", 'A');

Output on an ASCII system: A then 65. An ordinary character constant such as 'A' has type int in C, even though its value can be stored in char.

String literals

A string literal is a sequence of zero or more characters enclosed in double quotation marks. An ordinary string literal is an array of char with an automatically added null character.

char country[] = "Nepal";
printf("Welcome to BCA");
Nepal\0

Five letters plus the null terminator occupy six bytes. A string literal must not be modified directly; an array initialized from it, such as country, is modifiable.

3. Named constants

Using const

The const keyword is a type qualifier used to declare an object that cannot be modified through its const-qualified name.

const float TAX_RATE = 0.13f;
const int MAX_MARKS = 100;

MAX_MARKS = 120; is invalid. A const-qualified object can have a memory address. In traditional C, a const int is not automatically an integer constant expression for uses such as a case label.

Using #define

#define is a preprocessor directive that defines a macro. An object-like macro representing a fixed value is commonly called a symbolic constant. The preprocessor replaces macro names with replacement tokens before compilation.

#define PI 3.14159
#define MAX_MARKS 100
#define DAYS_IN_WEEK 7

area = PI * radius * radius; becomes area = 3.14159 * radius * radius; during preprocessing. A macro has no data type or storage of its own. Do not add an unnecessary semicolon; it becomes part of the replacement text.

5. Common mistakes

  • 010 is octal and represents decimal 8; 089 is invalid because octal digits cannot include 8 or 9.
  • 5, '5' and "5" are different: integer value 5, character code (53 on ASCII), and a string containing 5 plus a null character.

  • -15 is two tokens: unary minus and integer constant 15.
  • Uppercase names for symbolic constants are a convention, not a rule.

An escape sequence is a combination of source characters beginning with a backslash (\) used to represent a character that is special or difficult to write directly. Escape sequences are used in character constants and string literals.

6. Confusing points

  • printf("Hello/nWorld"); prints the slash and n normally. A forward slash is not a backslash.

An expression is a combination of operands and operators that specifies a computation and may produce a value or a side effect. Expressions can contain constants, variables, function calls and operators. A single constant or variable is also an expression; an operator is not required. A void expression has no value.

Statements
Unit 2 · Elements of C
Learning objectives
  • Define and classify statements.
  • Distinguish statements, expressions and declarations.
  • Understand sequence, selection, iteration and jump control.
1. Definition


A statement is a syntactically valid instruction or control construct in a C program that specifies an action. Statements perform calculations, assignments, function calls or control transfers.


total = price * quantity;
printf("%d", total);



The first assigns a value; the second displays it. Statements normally execute in sequence unless a control statement changes the flow.


2. Types of statements


Expression statement


An expression statement is an expression followed by a semicolon (;). It is commonly used to assign values, modify objects and call functions.


total = price * quantity;
count++;
salary += 5000;
printf("%d", total);



Compound statement (block)


A compound statement is a group of zero or more statements and declarations enclosed in curly braces. It is treated as one statement and introduces a block scope.


{
    int length = 15;
    int breadth = 10;
    int area = length * breadth;
    printf("%d", area);
}



Output: 150. Blocks can contain other blocks. No semicolon is needed after a standalone compound statement.


Selection statement


A selection statement selects a statement or block for execution according to a controlling expression.






  Statement
  Purpose






  if
  Executes a statement if a condition is true




  if-else
  Selects between two alternatives




  switch
  Selects a branch using an integer controlling expression






int marks = 65;
if (marks >= 40)
{
    printf("Pass");
}
else
{
    printf("Fail");
}



Output: Pass. The condition is checked first. If true, the first branch executes; otherwise, the second branch executes.


Iteration statement (loop)


An iteration statement repeats execution of a statement or block according to a controlling condition.






  Statement
  Purpose






  for
  Often used when repetition count is known




  while
  Checks the condition before the body




  do-while
  Executes the body at least once before checking the condition






for (int i = 1; i <= 5; i++)
{
    printf("%d ", i);
}



Output: 1 2 3 4 5. The initialization runs once, the condition is checked before each iteration, and the update runs after each body execution.


Jump statement


A jump statement transfers program control from the normal sequence to another point.






  Statement
  Purpose






  break
  Exits nearest enclosing loop or switch




  continue
  Skips the rest of the current loop iteration




  goto
  Transfers control to a label in the same function




  return
  Ends a function, optionally returning a value where allowed






for (int i = 1; i <= 10; i++)
{
    if (i == 6)
    {
        break;
    }
    printf("%d ", i);
}



Output: 1 2 3 4 5. When i equals 6, break exits the loop.


Labeled statement


A labeled statement is a statement marked with a label that serves as a target for transfer of control.






  Label
  Purpose






  identifier:
  Target for goto




  case constant:
  Target for matching integer constant expression in switch

  Target if no case matches in switch

6. Confusing points and common mistakes


Semicolons


Many statements end in a semicolon; blocks do not require one. A do-while statement requires a semicolon after its condition.


do
{
    a++;
} while (a < 10);



Do not place an accidental semicolon after an if or loop condition.


int marks = 25;
if (marks >= 40);
{
    printf("Pass");
}



This prints Pass because the if controls an empty statement, and the block executes independently. Remove the semicolon after the condition.


for (int i = 1; i <= 5; i++);
{
    printf("Hello");
}



This prints Hello once, not five times. The loop body is a null statement.


Curly braces and indentation


int marks = 25;
if (marks >= 40)
    printf("Pass\n");
    printf("Congratulations");



Only the first printf belongs to the if. Output: Congratulations. Indentation does not determine C's structure. Use braces to group both calls.


Lines and directives


a = 10; b = 20; sum = a + b; is three statements on one line. A statement may also span several lines. Write one per line for readability. #include <stdio.h> and #define PI 3.14159 are preprocessing directives, not statements.

Comments
Unit 2 · Elements of C
Learning objectives
  • Define single-line and block comments.
  • Explain how comments are handled in preprocessing.
  • Write useful comments and recognize mistakes.
1. Definition


A comment is a non-executable part of source code used to describe, explain or document a program. Comments improve readability, understandability and maintainability. During preprocessing, each comment is replaced by a single space, so comments do not become executable instructions.


// Calculate the area of a rectangle
int area = length * breadth;



The first line describes the purpose of the code.


2. Types of comments


Single-line comment


A single-line comment begins with // and continues until the end of the current logical line. It is commonly used for short explanations or descriptions. This syntax became standard in C99.


int length = 15;
int breadth = 10;
// Calculate the area
int area = length * breadth;
float taxRate = 0.13f; // VAT rate



Multi-line comment (block comment)


A multi-line comment begins with /* and ends with */. It may cover one or more lines and is useful for longer descriptions and documentation.


/*
    Calculate simple interest using
    principal, rate and time.
*/
float principal = 10000;
float rate = 8;
float time = 2;
float interest = principal * rate * time / 100;



A block comment may also appear on one line: /* Calculate simple interest */.

4. Complete example: circle calculations


#include <stdio.h>
#define PI 3.14159

/* Calculate circle area and circumference. */
int main(void)
{
    float radius = 7.5f;
    // Calculate required measurements
    float area = PI * radius * radius;
    float circumference = 2 * PI * radius;
    printf("Area: %.2f\n", area);
    printf("Circumference: %.2f\n", circumference);
    return 0;
}



Area: 176.71
Circumference: 47.12



5. How comments are handled


During preprocessing, comments are replaced by spaces before compilation. This preserves token separation. For example, int/**/age; is treated as int age;, not intage;. Comments are not counted as C language tokens or statements. They do not generate executable instructions; removing comments correctly while preserving necessary whitespace does not change ordinary program behavior.


6. Common mistakes


Nested block comments


/* Outer comment
   /* Inner comment */
   End of outer comment
*/



This is invalid. The first */ closes the original comment, leaving invalid code after it. C does not support nested block comments.


Comment symbols inside strings


printf("Welcome // to C\n");
printf("Learn /* C Programming */");



Welcome // to C
Learn /* C Programming */



These symbols are part of string literals, not comments.


Unclosed comments


/* Calculate total marks
int total = 250;



An unclosed block comment requires a compilation diagnostic. Add */ where the comment should end.


Counting tokens


int marks = 85; // Student marks contains five tokens: int, marks, =, 85, ;. The comment is excluded.


Good commenting practices


Write short, meaningful comments. Explain why a calculation or decision is needed, instead of repeating obvious code. Update comments whenever the code changes.


// Minimum age required for registration
int minAge = 20;
